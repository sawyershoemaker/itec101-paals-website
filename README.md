# PAALS website

Three-page ITEC 101 class project using HTML and embedded CSS.

Run a local static server to preview. Run `python .github/scripts/check_site.py` to check links, images, the local font, and explicit per-page size budgets. The ASCII animations use CSS and include a reduced-motion alternative. Passing changes on `main` publish through GitHub Pages; this preview branch has not been deployed.

AI assistance and source credits are recorded in each page's HTML comments.
